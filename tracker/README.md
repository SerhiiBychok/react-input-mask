# Самопочуття — трекер симптомів для iPhone

Невеликий офлайн‑застосунок (PWA) на один екран: торкнувся картки — записано «зараз».
Показує, коли це було востаннє, веде історію по днях і дозволяє додавати власні категорії.

Стандартні категорії: головний біль, коліно ліве, коліно праве, цукор. Їх можна перейменувати,
змінити значок чи колір, видалити або додати нові.

## Як поставити на iPhone

1. Відкрийте сторінку `tracker/` цього сайту в **Safari** на телефоні
   (наприклад, `https://<ваш-домен>/tracker/`).
2. Натисніть кнопку **«Поділитися»** (квадрат зі стрілкою внизу екрана).
3. Виберіть **«На Початковий екран»** → **«Додати»**.
4. Відкривайте з головного екрана як звичайний застосунок. Працює без інтернету.

## Що вміє

- **Зараз** — картки категорій. Торкання = запис з поточним часом. Одразу показується
  підказка з кнопками «Змінити» (виправити час або додати нотатку) і «Скасувати».
  На картці видно «востаннє: 2 год тому», точний час і кількість за 7 днів.
- **Історія** — усі записи по днях, фільтр за категорією, підсумок (усього / 7 днів / 30 днів).
  Торкання запису відкриває редагування: категорія, дата‑час, нотатка, видалення.
- **Категорії** — додати, перейменувати, змінити значок і колір, переставити, видалити.
  Тут же експорт / імпорт резервної копії (JSON) і очищення записів.

## Дані

Усе зберігається лише на телефоні (`localStorage`). Сервера немає, нічого нікуди не надсилається.
Періодично робіть **Експорт** у «Категорії → Дані» — файл можна зберегти у «Файли» або iCloud
і потім відновити через **Імпорт**.

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html` | увесь застосунок (HTML + CSS + JS) |
| `manifest.webmanifest` | назва, іконки, повноекранний режим |
| `sw.js` | кешування для роботи офлайн (при оновленні коду збільшіть `CACHE` версію) |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | іконки для iOS та маніфесту (згенеровано з `icon.svg`) |
